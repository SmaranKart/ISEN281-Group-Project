# ISEN281-Group-Project

## SolidWorks Simulation Report Collaboration

This repository contains a shared `.sldrpt` file for collaborative work among team members.

### Project File
- `project_report.sldrpt` - Main SolidWorks Simulation Report file

### Collaboration Workflow
1. Pull the latest version before making changes: `git pull`
2. Make your changes to the `.sldrpt` file in SolidWorks
3. Stage and commit your changes: `git add project_report.sldrpt && git commit -m "Description of changes"`
4. Push your changes: `git push`

### Important Notes
- Always pull before starting work to avoid conflicts
- Communicate with team members to avoid editing simultaneously
- Use descriptive commit messages to track changes
- Binary files like `.sldrpt` cannot be merged - if conflicts occur, one version must be chosen
- Ensure all team members use compatible SolidWorks versions
